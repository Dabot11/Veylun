# Referencias visuales

Se recibieron y revisaron las 24 imágenes de personajes: seis en cada una de
las carpetas `ruen/`, `corrupt-sprout/`, `wandering-spirit/` y
`ancestral-guardian/`. Cada carpeta conserva los originales y un inventario
con dimensiones y hashes. Sus README clasifican vistas y detallan el diseño.
Las entregas individuales sustituyen el ZIP conjunto que excedía 32 MiB.

El Claro del despertar se revisó a partir de la imagen visible en el chat.
El binario de esa imagen no está disponible en el checkout; la ruta de macOS
mencionada no es una ruta accesible en el entorno Linux.

Estas imágenes son conceptos 2D, no modelos ni animaciones. Permanecen fuera
de `public/` para que el juego descargue solamente recursos optimizados.
Las mallas provisionales se generan en `src/assets/characters.ts`.
